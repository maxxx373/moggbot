# Бот @justmoggbot

Простой бот с меню:

- **🚀 Открыть mogg** — запускает мини-апп;
- **💬 Поддержка** и **🤝 Сотрудничество** — контакты;
- **💎 Подписка mogg Pro** — что даёт Pro и кнопка, которая открывает приложение сразу на окне оплаты;
- **🔒 Политика конфиденциальности** — ссылка на `privacy.html`.

Разделы открываются в том же сообщении, кнопка «Назад» возвращает меню. На любое другое сообщение бот отвечает меню. Команды: `/start`, `/support`, `/pro`, `/collab`, `/privacy`.

Код — `bot/index.js`, одна функция Yandex Cloud Functions на Node.js без зависимостей. Картинка приветствия — `bot/cover.jpg`, она берётся с GitHub Pages.

## Как запустить (≈10 минут)

1. В [консоли Yandex Cloud](https://console.yandex.cloud) открой **Cloud Functions → Создать функцию**. Назови, например, `mogg-bot`.
2. Создай версию:
   - среда выполнения **Node.js 18** (или новее);
   - способ — **Редактор кода**, файл `index.js`, вставь содержимое `bot/index.js`;
   - точка входа — `index.handler`;
   - таймаут — 10 секунд, память — 128 МБ.
3. В той же версии добавь **переменные окружения**:
   - `BOT_TOKEN` — токен бота от @BotFather;
   - `SUPPORT_TG` — ник поддержки без `@` (сейчас `paradox112`);
   - `SUPPORT_EMAIL` — `mogg_help@mail.ru`.
4. На странице функции включи **«Публичная функция»**.
5. Скопируй ссылку вызова (`https://functions.yandexcloud.net/…`) и открой в браузере, добавив в конце `?setup=1`. Бот сам подключит вебхук, команды, описание и кнопку «Открыть» слева от поля ввода.
   - Если в ответе есть `"ok": true` — готово, напиши боту `/start`.
   - Если пришло предупреждение, что у бота уже стоит другой вебхук, — значит, его ставил старый бэкенд. Тогда напиши мне, разберёмся, прежде чем переключать с `&force=1`.

## Как поменять контакты поддержки

Поменяй переменную `SUPPORT_TG` или `SUPPORT_EMAIL` в настройках функции и создай новую версию. Код трогать не нужно.
