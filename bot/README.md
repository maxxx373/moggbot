# Бот @justmoggbot

Простой бот с меню:

- **🚀 Открыть mogg** — запускает мини-апп;
- **💬 Поддержка** и **🤝 Сотрудничество** — контакты;
- **💎 Подписка mogg Pro** — что даёт Pro и кнопка, которая открывает приложение сразу на окне оплаты;
- **🔒 Политика конфиденциальности** — ссылка на `privacy.html`.

Разделы открываются в том же сообщении, кнопка «Назад» возвращает меню. На любое другое сообщение бот отвечает меню. Команды: `/start`, `/support`, `/pro`, `/collab`, `/privacy`.

Код — `bot/index.js`, одна функция Yandex Cloud Functions на Node.js без зависимостей. Картинка приветствия — `bot/cover.jpg`, она берётся с GitHub Pages.

## Как развёрнуто сейчас

- Функция **`mogg-bot`** в Yandex Cloud (каталог с бэкендом `mogg-ai`): Node.js 22, точка входа `index.handler`. Переменные окружения: `BOT_TOKEN`, `SUPPORT_TG`, `SUPPORT_EMAIL`, `WEBHOOK_URL`.
- API Gateway **`mogg-bot-gw`** принимает вебхук Telegram на `/bot` и вызывает функцию от имени сервисного аккаунта `mogg-deploy`. Поэтому функция не публичная.
- Из российских дата-центров `api.telegram.org` недоступен. Поэтому бот сам в Telegram не ходит: действие (отправить меню, сменить экран) возвращается прямо в ответе на вебхук. Так разрешает Bot API.
- Вебхук, команды, описание и кнопку «Открыть» ставят запросом к Bot API не из Яндекса (`?setup=1` из облака упрётся в таймаут).

## Как поменять контакты поддержки

В консоли: функция `mogg-bot` → «Редактор» → поменять `SUPPORT_TG` или `SUPPORT_EMAIL` → «Сохранить изменения». Код трогать не нужно.
