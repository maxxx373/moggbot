# Развёртывание бэкенда mogg в Yandex Cloud

Код функций лежит в репозитории maxxx373/moggbot, ветка `main`. Каждую функцию обновляем в консоли
Yandex Cloud → Cloud Functions → функция → «Редактор». Всё делать в том же каталоге, где уже живут функции mogg.

Общее для всех функций (если не сказано иное): среда выполнения **Node.js 22**, точка входа **`index.handler`**,
файл один — `index.js`. Существующие переменные окружения и сервисный аккаунт **не удалять**, только добавлять.

## 1. mogg-chat (чат-характеры)
- Заменить `index.js` содержимым `chat/index.js`.
- Переменные не меняются (BOT_TOKEN, FOLDER_ID, UPSTREAM).
- Что изменилось: правила ИИ только серверные (клиентские игнорируются), лимит «переписать текст» 30/час и 1500 символов,
  подпись Telegram действует 2 суток.

## 2. mogg-pay (оплата + рефералка + сообщения о проблемах)
- Заменить `index.js` содержимым `pay/index.js`.
- Переменные не меняются. Можно (необязательно) добавить `REF_DAYS=7`, `REF_MAX=20`.
- Проверка: открыть в браузере адрес шлюза `…apigw.yandexcloud.net/pay` → ответ `{"ok":true,"service":"mogg-pay",...}`.

## 3. mogg-bot (бот @justmoggbot)
- Заменить `index.js` содержимым `bot/index.js`.
- Добавить переменные:
  - `BUCKET` — то же значение, что у mogg-pay;
  - `OWNER_ID` — Telegram ID владельца (узнать у бота @userinfobot).
- Вкладка «Сервисный аккаунт»: выбрать тот же сервисный аккаунт, что у mogg-pay (ему нужен доступ на чтение бакета).
- Проверка: написать боту `/reports` → «Сообщений о проблемах пока нет 🙌».

## 4. Закрыть прямой доступ к функциям
Для mogg-ai, mogg-chat, mogg-pay, mogg-bot: «Обзор» → выключить «Публичная функция»,
**только если** шлюз API (API Gateway) вызывает функцию от имени сервисного аккаунта
(в спецификации шлюза у интеграции `cloud_functions` указан `service_account_id`, а у аккаунта роль `functions.functionInvoker`).
Если service_account_id нет — сначала добавить его в спецификацию шлюза, иначе приложение перестанет получать ответы.
После изменения: открыть мини-апп, отправить сообщение в чат и открыть окно Pro — всё должно работать.

## 5. mogg-ai (основной бэкенд) — на проверку
Кода mogg-ai нет в репозитории. Скопировать его `index.js` (и другие файлы, если есть) в репозиторий,
в ветку `claude/relaxed-pascal-jpretf`, папку `ai/` — **без секретов** (значения переменных окружения не копировать).
Известная проблема: функция принимает системные правила ИИ (`rules`, `context.rules`) от клиента — их нужно игнорировать
и брать только серверные (как сделано в chat/index.js, константа SERVER_RULES).
